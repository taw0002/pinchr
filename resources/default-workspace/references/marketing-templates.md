# Marketing Content Templates

Reference templates for social media posts. Adapt these to your specific product, message, and audience. Templates are starting points — don't use them verbatim.

Placeholders use `{curly_braces}`. Replace all placeholders before submitting for review.

---

## 1. Product Announcement

Use when launching a new product, major version, or entering a new market.

### X / Twitter
```
{product_name} is here. 🚀

{one_sentence_value_prop}

{key_feature_1}
{key_feature_2}
{key_feature_3}

Try it → {link}

{#hashtag1} {#hashtag2}
```
_Target: under 280 chars. Front-load the hook._

### LinkedIn
```
We've been building {product_name} for the last {timeframe}, and today it's live.

{problem_statement} — that's what we kept hearing from {target_audience}. So we built something about it.

{product_name} helps you:
→ {benefit_1}
→ {benefit_2}
→ {benefit_3}

We're not claiming to have all the answers, but we think this is a solid step forward.

Link in comments. Would love to hear what you think.

{#hashtag1} {#hashtag2} {#hashtag3}
```
_Put the link in the first comment to boost reach. End with engagement prompt._

### Reddit
```
Title: I built {product_name} — {short_value_prop}

Hey {subreddit_community},

I've been working on {product_name} for {timeframe}. The problem I kept running into was {problem_statement}, and I couldn't find a tool that handled it well.

So I built one. Here's what it does:
- {feature_1}: {why_it_matters}
- {feature_2}: {why_it_matters}
- {feature_3}: {why_it_matters}

It's {pricing_model — free/paid/freemium}. {link}

Happy to answer any questions or hear feedback. I know this space has a lot of tools already — genuinely curious what you think is missing.
```
_Be transparent about who you are. Invite honest feedback. Don't hype._

## 2. Feature Highlight

Use when shipping a specific feature update or improvement.

### X / Twitter
```
New in {product_name}: {feature_name}

{what_it_does_in_one_line}

{before_vs_after_or_key_detail}

{link}
```
_Keep it tight. One feature, one message._

### LinkedIn
```
Small update, big impact.

We just shipped {feature_name} in {product_name}.

The problem: {pain_point_this_solves}

What changed: {clear_explanation_of_the_feature}

Why it matters: {concrete_benefit — time saved, errors prevented, workflow improved}

This came directly from user feedback — {brief_story_or_quote_if_available}.

What feature would make the biggest difference in your workflow?

{#hashtag1} {#hashtag2} {#hashtag3}
```
_Connect feature to pain point. Credit users when possible._

### Reddit
```
Title: We just added {feature_name} to {product_name} — here's why

Quick update for anyone following along:

We shipped {feature_name} this week. The short version: {what_it_does}.

A few of you mentioned {pain_point} in previous threads, and this is our take on solving it. 

Here's how it works: {brief_explanation}

Would love feedback, especially from anyone who's been dealing with {related_problem}. What would you want to see next?
```
_Reference community conversations. Show you're listening._

## 3. Blog Post Promotion

Use when sharing a blog post, guide, case study, or long-form content.

### X / Twitter
```
{compelling_insight_from_the_post}

We wrote about {topic} — {what_the_reader_will_learn}.

Read → {link}
```
_Lead with the insight, not "we wrote a blog post." Nobody cares that you wrote it — they care what's in it._

### LinkedIn
```
{hot_take_or_surprising_stat_from_the_post}

We dug into {topic} and found some things worth sharing:

📌 {key_takeaway_1}
📌 {key_takeaway_2}
📌 {key_takeaway_3}

The full breakdown is on our blog (link in comments).

What's been your experience with {topic}?

{#hashtag1} {#hashtag2} {#hashtag3}
```
_Give enough value in the post itself that it works even without clicking the link._

### Reddit
```
Title: {insight_or_question_from_the_post} — {qualifier}

I wrote up {topic} after {context — personal experience, research, user questions}.

TL;DR:
- {key_point_1}
- {key_point_2}
- {key_point_3}

Full post here if you want the details: {link}

Curious if others have run into the same thing — {discussion_question}.
```
_TL;DR is mandatory on Reddit. Respect people's time._

## 4. Community Engagement / Question Posts

Use to spark conversation, learn from the audience, or build community presence.

### X / Twitter
```
Genuine question for {audience}:

{question}

I'll go first: {your_answer}
```
_"I'll go first" dramatically increases responses. Keep the question specific, not vague._

### LinkedIn
```
I've been thinking about {topic} lately.

{context — 2-3 sentences on why this is on your mind}

{specific_question}

I've seen it go both ways:
→ {perspective_a}
→ {perspective_b}

Where do you land? Curious to hear from people who've actually dealt with this.

{#hashtag1} {#hashtag2}
```
_Frame both sides to make it safe to disagree. "Actually dealt with this" filters for quality responses._

### Reddit
```
Title: {specific_question} — looking for real experiences

Hey {subreddit},

{context — why you're asking, what you've tried, what you've found so far}

Specifically wondering:
1. {sub_question_1}
2. {sub_question_2}

I've searched through past threads and found {what_you_found}, but {why_you_still_need_input}.

Thanks in advance.
```
_Show you've done homework. Reddit hates lazy questions that could be Googled._

## 5. Thought Leadership / Opinion Posts

Use to share a perspective, challenge conventional wisdom, or position on an industry topic.

### X / Twitter
```
Unpopular opinion: {take}

{2-3 sentences of reasoning}

Agree? Disagree? Tell me why I'm wrong.
```
_Strong takes get engagement. But only post opinions you can actually defend._

### LinkedIn
```
{bold_opening_statement}

I know that's not what most people in {industry} say. Here's why I think differently.

{paragraph_1 — the conventional wisdom and why it exists}

{paragraph_2 — what you've seen that contradicts it}

{paragraph_3 — your alternative perspective with evidence}

I could be wrong. But after {experience_qualifier — years in the industry, building X, talking to Y customers}, this is where I've landed.

What's your take?

{#hashtag1} {#hashtag2} {#hashtag3}
```
_"I could be wrong" is powerful on LinkedIn. Shows confidence without arrogance._

### Reddit
```
Title: {take} — change my mind (or confirm it)

{context — what led you to this opinion}

My argument:
1. {point_1_with_evidence}
2. {point_2_with_evidence}
3. {point_3_with_evidence}

The counter-argument I keep hearing is {common_objection}, and here's why I don't fully buy it: {rebuttal}.

But I'm open to being convinced otherwise. What am I missing?
```
_Steelman the opposing view. Reddit respects intellectual honesty._

---

## Usage Notes

- **Don't copy-paste these templates as-is.** They're frameworks. The final post should sound natural, not formulaic.
- **Adapt the tone to your specific brand voice.** These are neutral defaults.
- **Test and iterate.** Track which structures get the best engagement and evolve the templates.
- **Cross-posting is not copy-pasting.** The same announcement needs three different posts for three different platforms.
- **Character counts matter for X.** Always verify before submitting.
