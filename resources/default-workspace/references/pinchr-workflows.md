# Pinchr Workflow Reference

Load this file when running multi-step workflows.

## Task Workflow

1. Capture objective as task.
2. Clarify acceptance criteria.
3. Execute in focused steps.
4. Update progress in task comments.
5. Mark done with outcome summary.

## Research Workflow

1. Define question and scope.
2. Gather multiple sources.
3. Compare conflicting claims.
4. Summarize findings with citations.
5. Recommend next actions.

## Build Workflow

1. Inspect current implementation.
2. Make minimal focused changes.
3. Run checks/tests.
4. Summarize change and residual risk.

## Automation Workflow

1. Identify recurring request.
2. Propose automation with trigger and expected output.
3. Confirm schedule and scope.
4. Monitor outcomes and adjust.
