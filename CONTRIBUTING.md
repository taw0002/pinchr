# Contributing to Pinchr

Thanks for your interest in contributing! This guide will be expanded soon.

## Getting Started

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-feature`)
3. Make your changes
4. Run the build to verify (`yarn dist`)
5. Commit with a clear message
6. Push and open a Pull Request

## Code Style

- TypeScript for all source code
- Tailwind CSS for styling
- Follow existing patterns in the codebase

## Reporting Issues

Use [GitHub Issues](https://github.com/taw0002/pinchr/issues) for bugs and feature requests.

For security vulnerabilities, see [SECURITY.md](SECURITY.md).
